# Images du site

Dépose ici les photos utilisées sur le site de Timéo.

- Formats conseillés : `.webp`, `.jpg` ou `.png`.
- Utilise des noms simples, sans espaces ni accents (ex. `portrait-rue-01.webp`).
- Pour afficher une image dans `index.html`, utilise son chemin relatif : `images/portrait-rue-01.webp`.

Les fichiers ajoutés dans ce dossier seront disponibles dans le dépôt GitHub et pourront être utilisés par le site.
