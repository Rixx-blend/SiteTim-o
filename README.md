# Site Timéo Massot

Site vitrine de photographie de rue et de prestations photo, réalisé en HTML, CSS et JavaScript.

**Site en ligne :** https://site-timeo.vercel.app  
**Code source :** https://github.com/Rixx-blend/SiteTim-o

## Fonctionnalités

- Galerie photo avec affichage en grand format.
- Présentation des prestations.
- Animations et effets au défilement.
- Formulaire de contact (à connecter à un compte Formspree).
- Mise en page responsive pour ordinateur et mobile.

## Lancer le projet

Le site est statique : aucun outil de compilation n'est nécessaire.

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/Rixx-blend/SiteTim-o.git
   ```
2. Ouvrez le dossier.
3. Ouvrez `index.html` dans un navigateur.

Pour travailler avec un serveur local, utilisez l'extension Live Server de VS Code ou tout serveur HTTP statique.

## Personnalisation

- **Contenu et structure :** `index.html`
- **Styles :** CSS intégré dans `index.html`
- **Interactions :** JavaScript intégré dans `index.html`
- **Images :** dossier `images/`

Remplacez les images de démonstration par vos propres visuels et vérifiez les chemins des fichiers. Le formulaire de contact utilise actuellement un identifiant Formspree à configurer : remplacez le placeholder par votre propre endpoint.

## Déploiement

Le dépôt peut être importé dans [Vercel](https://vercel.com/). Pour un site statique, les réglages de build peuvent rester vides. Une connexion Git permet de déployer automatiquement les changements poussés sur la branche principale.
